# GPO Evaluation Toolkit

PowerShell tools that compare Group Policy Objects, find deprecated
settings, map settings to Microsoft Intune, and plan a GPO consolidation.
Requires Windows PowerShell 5.1. Excel output and the plans use the
ImportExcel module (the scripts offer to install it for the current user).

## Quick start

```powershell
cd "Group Policy Scripts\GPO Evaluation"
.\Start-GPOToolkit.ps1
```

The menu:

| # | Action | Script it runs |
|---|---|---|
| 1 | Compare GPO XML exports (`Get-GPOReport -ReportType Xml`) | `Scripts\Compare-GPOXml.ps1` |
| 2 | Compare GPResult HTML reports (`gpresult /h`) | `Scripts\Compare-GPOHtml.ps1` |
| 3 | Build an Intune policy plan from compare output | `Scripts\New-IntunePolicyPlan.ps1` |
| 4 | Build a GPO consolidation plan (baseline, hardening, branding per site) | `Scripts\New-GpoConsolidationPlan.ps1` |
| 5 | Import manual GPO-to-Intune mapping workbooks | `Scripts\Import-IntuneMappingWorkbook.ps1` |
| 6 | Check that the toolkit files and the ImportExcel module are present | - |

The menu asks for the folders and files each action needs; press Enter to
accept a default in [brackets]. The compare scripts then ask their own
questions (output file prefix, CSV or Excel, exclusions). Before running,
the menu prints the equivalent direct command. Folders used earlier in the
session are offered as defaults, so the output of a compare run is the
default input of actions 3 and 4.

A typical order: 1 (and/or 2), then 3 or 4.

## Folders

```
GPO Evaluation\
  Start-GPOToolkit.ps1      the menu
  README.md                 this file
  CHANGES.md                version history
  Scripts\                  the five scripts (each can also be run directly)
  Modules\                  PowerShell modules used by the scripts
  Data\                     shared reference and mapping files
    DeprecatedPoliciesReference.md   deprecated and legacy policies
    intunemapping.json               general Intune mapping rules
    IntunePolicyMappings.json        per-policy Intune mappings (generated by action 5)
    IntuneMigrationExclusions.json   optional exclusions for the compare scripts
  Config\                   your own configuration
    GpoRoles.example.csv             format of GpoRoles.csv (action 4)
    ConsolidationRules.example.json  format of ConsolidationRules.json (action 4)
```

Files you create in `Config` stay on your computer: `.gitignore` keeps
`GpoRoles.csv`, `ConsolidationRules.json`, `IntuneMappingRedactions.txt`
and `IntunePolicyMappings.Internal.json` out of the repository, because
they contain organization names. Action 4 offers to copy the example files
when the real ones are missing.

## Running a script directly

Every script keeps its parameters; run it from any folder. Defaults point
to the `Modules`, `Data` and `Config` folders.

```powershell
.\Scripts\Compare-GPOXml.ps1 -XmlFolder "C:\GPOProject\XML" -OutputFolder "C:\GPOProject\Output" -OutputFormat Excel
.\Scripts\Compare-GPOHtml.ps1 -HtmlFolder "C:\GPOProject\HTML" -OutputFolder "C:\GPOProject\Output" -OutputFormat Excel
.\Scripts\New-IntunePolicyPlan.ps1 -InputPath "C:\GPOProject\Output\GPOCompareXml.xlsx"
.\Scripts\New-GpoConsolidationPlan.ps1 -InputPath "C:\GPOProject\Output\GPOCompareXml.xlsx", "C:\GPOProject\HtmlOutput"
.\Scripts\Import-IntuneMappingWorkbook.ps1 -Path "C:\GPOProject\Mappings" -Rebuild
```

Full help: `Get-Help .\Scripts\<script name>.ps1 -Full`.
